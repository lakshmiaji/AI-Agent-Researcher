# ⭐ AI Agent Researcher

### Autonomous Research Paper Generator using Streamlit, FastAPI, LangGraph & Gemini 2.5 Pro

**AI Agent Researcher** is an end-to-end autonomous research assistant that generates complete **LaTeX and PDF research papers** from scratch.  
The system uses **multi-agent workflows**, **scholarly search**, and **advanced LLM reasoning** to explore topics, gather references, and produce academic-grade papers.

---

## 🚀 Tech Stack

### **Frontend**
- Streamlit

### **Backend**
- FastAPI

### **LLM**
- Google Gemini 2.5 Pro

### **Workflow Orchestration**
- LangGraph

### **AI Agents**
- Custom multi-tool intelligent agents

### **PDF Rendering**
- Tectonic (XeLaTeX-compatible)

### **PDF Reading**
- PyPDF2

### **Search**
- arXiv API
